# Conceitos visuais aprovados

Estas imagens são a referência visual do protótipo. Elas definem a direção de
cores, tipografia, espaçamento, hierarquia, componentes e estados das áreas
pública e administrativa.

- `catalogo-mobile.png`: catálogo público e cartões de presentes.
- `detalhe-reserva-mobile.png`: detalhe do presente e fluxo de reserva.
- `pix-impressao-mobile.png`: contribuição por Pix e prévia para impressão.
- `painel-admin-desktop.png`: resumo e operações administrativas.

O produto continua sendo somente um protótipo visual: não há back-end, banco de
dados, autenticação real nem persistência entre recarregamentos.
